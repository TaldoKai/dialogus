Approach

CONTEXT

A string without context is a shot in the dark. Before translating, I make sure I understand who's speaking, to whom, and at what point in the game that line lands.

VOICE

A formal NPC doesn't talk like a grunt in the trenches. I keep each character's voice consistent from start to finish — slang, hesitation, personality quirks.

SPACE

Every UI button has a character limit. Localizing also means fitting — without losing meaning or sounding clipped and robotic.
